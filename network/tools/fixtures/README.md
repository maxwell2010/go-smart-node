# Launch allocation fixtures

`launch-four-validator-ci-allocation.json` preserves the historical allocation
used by the four-validator rehearsal from the v1.0.0 source tree. The development
workflow validates that isolated fixture against this file.

The current proposed public allocation lives in
`../../docs/ru/public-launch-allocation.draft.json`. It requires approval,
authenticated addresses and a new isolated rehearsal before public launch.
An aggregate comparison of the historical fixture cannot approve or validate
the new founder, treasury or operator wallet distribution.
