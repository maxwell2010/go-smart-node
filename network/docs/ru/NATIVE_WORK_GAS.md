# Газ нативной обработки EVM-транзакций

Для отдельной новой сети нативный обработчик успешной EVM-транзакции
работает в оставшемся лимите газа подписанной транзакции. Одна единица
SDK gas соответствует одной единице EVM gas. Возвращены стандартные
стоимости KV и transient KV: нулевые настройки EVM не делают нативные
чтения и записи бесплатными.

После EVM и нативной обработки применяется один минимум комиссии:
`max(EVM gas после refund + native gas, gasLimit * MinGasMultiplier)`.
Минимум не уменьшает доступный обработчику бюджет исполнения.
При исчерпании бюджета транзакция использует весь лимит газа. Другая
ошибка обработчика оплачивает фактическую работу с указанным минимумом.
Комиссия и nonce сохраняются по правилам ante; перевод, записи и события
отменённой операции не сохраняются. События успешной обработки передаются
один раз через commit cache, без повторного ручного добавления.
Для откатившейся EVM-транзакции
финансовый обработчик не запускается.

`eth_estimateGas` выполняет тот же обработчик после симуляции EVM
в отдельном отбрасываемом cache. Он видит результаты симуляции, но
не изменяет состояние сети. Лимит газа проверяется совместно, включая
случай простого перевода, который раньше мог оцениваться в 21000.
Оценка зависит от текущего состояния: изменение состояния до включения
транзакции по-прежнему может изменить необходимый лимит.

Регрессия `native_hook_gas_and_rollback` использует настоящие подписи,
ante, FinalizeBlock и Commit. В качестве ограниченной работы тестовый
обработчик читает и меняет метаданные нативного coin keeper. Проверяются
оценка без записи, комиссия и nonce, обычный успех, повышенный лимит,
отказ обработчика, OOG и отсутствие событий успеха при откате.
Это проверка механизма учёта, а не завершённого финансового процессора.

Внутренние вызовы `ApplyMessage`, включая governance и будущие IBC
callbacks, не проходят автоматически через `ApplyTransaction`.
До включения финансовых маршрутов им нужен единый подтверждённый
процессор результатов с учётом газа и атомарным откатом. Само наличие
этого исправления не подтверждает готовность этих маршрутов.

Изменение относится только к новой сети. Оно не применяется при
историческом воспроизведении Decimal mainnet.
