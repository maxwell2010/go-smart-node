# MintCandy Node 1.0.0

Этот документ описывает программный выпуск `mcnd` 1.0.0. Наличие пакета,
точную ревизию, SHA256 и аттестацию проверяйте на
[странице выпуска](https://github.com/maxwell2010/go-smart-node/releases/tag/v1.0.0).
Выпуск программы не объявляет запуск публичной сети.

## Назначение

`mcnd` запускает отдельную MintCandy Network на современном стеке Cosmos
SDK, CometBFT, EVM и IBC. Legacy-сборка в корне репозитория сохранена для
отдельной работы с историческим Decimal. Данные, chain ID и бинарники этих
семейств нельзя смешивать при обновлении действующей сети.

## Что входит

- Нативный консенсус с регистрацией валидаторов, сменой набора и весами
  DEL/NFT-стейков. Управление учитывает валидаторов и делегаторов.
- DEL-делегации и hold-позиции; изолированное DEL-обеспечение NFT;
  конвертация утверждённого DRC20-обеспечения с пользовательским `minOut`.
- Общий путь ручного и автоматического complete: выплата, rollback и
  повтор; возврат NFT до 1024 исходных единиц в проверенном лимите 24 млн gas.
- Штрафы за простой и двойную подпись. Для большого числа позиций обработка
  продолжается страницами после перезапуска, а вывод ждёт окончания штрафа.
  Подтверждённый duplicate consensus key исключается при приёме доказательств,
  независимо от времени завершения финансовых страниц.
- Награды валидаторам и делегаторам из комиссий DEL; этот механизм не выпускает
  новые DEL. Комиссия оператора выделяется из его доли, остаток получают
  делегаторы. Автоматический проход
  начинается после интервала 120 блоков; начисленные права сохраняются при
  пополнении, полном выходе, ошибке перевода и перезапуске.
- Оплата EVM-операции каноническим DRC20 с доступной публичной конвертацией
  резерва при нулевом нативном балансе:
  EIP-712 авторизация, публичная конвертация, отдельный nonce, CLI envelope,
  REST policy/quote и отражение конвертации в RPC receipt.
- Создание канонических безрезервных токенов и разрешённые операции владельца.
  Безрезервный токен не получает доступ к оплате gas из несуществующего резерва.
- Нативный ICS-20 и настоящий Hermes: handshake, перевод, возврат,
  восстановление незавершённого пакета, error acknowledgement и timeout.
- Согласованное обновление, миграция, backup rollback, state sync,
  восстановление недостающего последнего блока и проверки подписей.

## Проверенная нагрузка и ограничения

Проверка 10, 100 и 1000 позиций использовала настоящую EVM, подписанные
операции, LevelDB restart и повтор потерянного до commit блока. AppHash
совпал. В DEL-сценарии на уровне Keeper расход одной страницы штрафа составил примерно
310 тысяч SDK gas и практически не зависел от размера общего списка.

`MaxDelegations=1000` означает нативные записи на одного валидатора. Для
холодного финансового genesis остаётся отдельный предел 16 исходных позиций.
Прямых голосующих по одному предложению - до 256; это отдельное ограничение.
Страница наград ограничена 64 получателями и 4 млн SDK gas, попытка - 2 млн.
Проход может продолжаться дольше одного интервала. Это функциональные
нагрузочные проверки, а не обещание TPS или достаточности любого сервера.

Начисление комиссий H-1 выполняется в начале H по состоянию позиций после
H-1. Это не отдельный снимок долей для каждой транзакции внутри H-1.
Защищены уже начисленные права. Иерархическое округление внутри
валидатора сохраняет все минимальные единицы DEL, но может менять получателя
последних wei по сравнению с прежним глобальным распределением остатков.

## Совместимость сервисов

EVM-адрес и ключ можно использовать с отдельным chain ID MintCandy; балансы
Decimal от этого не переносятся. Нативный профиль допускает определённые
системные EVM-маршруты. Развёртывание произвольных dApp-контрактов и обычный
EVM value CALL на EOA в этом профиле не включены. Нативный перевод выполняется
через SDK `MsgSend`/`MsgMultiSend`; это нужно учитывать при подключении кошелька.

Обычный `eth_sendRawTransaction` оплачивает поддержанную операцию нативной
монетой. DRC20 fee envelope передаётся бинарно через Comet/Cosmos broadcast.
Результат продажи сверх комиссии и возврат gas остаются нативной монетой.
Полный финансовый genesis export/import пока закрыт; используйте проверенные
резервные копии, snapshots и согласованный обработчик обновления.

DEX, инвестиционный vesting, собственный stablecoin, DePIN и MEV относятся
к следующим этапам. Мост к Decimal остаётся отдельным прототипом и не
заявляется готовым для реальных переводов.
