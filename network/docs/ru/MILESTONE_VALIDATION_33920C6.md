## Фактический запуск ноды

Оба бинарника собраны из `33920c6` на Ubuntu 24.04 с Go 1.26.10,
без тестовых тегов. CI сравнил перечни Go/embed-входов до и после сборки,
проверил VCS-ревизию обоих бинарников и метаданные 247 зависимостей `mcnd`.
Два приложения работали только в изолированных Linux net namespace с loopback.
Новые home, ключи и базы создавались для тестов и удалялись при завершении.

Daemon получил Cosmos chain ID `mintcandy_990001-1` и EVM chain ID `990001`.
Проверены свежий genesis, операторский ключ `eth_secp256k1` с coin type 60,
подпись `gentx`, первый старт до блока 3 и перезапуск до блока 5. Подписанный
перевод через native bank проверил точную комиссию, списание, зачисление и
общий SDK/EVM nonce. Неверный домен при перезапуске отклонён с кодом 1
без изменения home. Профиль `rpc-ibc` применён к новому home. Срок прогона
не позволял проверить удаление блоков после окна хранения.

## Шесть фаз ICS20 с Hermes

Контрагент `ibc-reference-1` и `mcnd` создали `channel-0` на обеих сторонах.
Использован официальный архив Hermes `v1.13.3` с проверенным SHA256
бинарника. Его собственная команда версии вывела `hermes 1.13.2+bab3b80`.
Во всех шести фазах итог `PASS`:

1. Создание клиентов, соединения и канала.
2. Перевод нативного DEL контрагенту.
3. Возврат IBC-ваучера и зачисление DEL.
4. Перезапуск обеих нод на тех же бинарниках с сохранением commitment пакета № 2.
5. Возврат средств по error acknowledgement пакета № 3.
6. Возврат средств по наступившему timeout пакета № 4.

Отчёт содержит 26 сверок комиссий включённых транзакций. В итоговом JSON
Hermes указаны `TWO_PROCESS_HERMES_PASS` и `release_gate: true`, это результат
шести фаз изолированного стенда. Полные хеши бинарников, отчётов и архива
сохранены в [сводке доказательств](evidence/milestone-33920c6-20261103/summary.json).
Срок хранения архива process CI составлял 7 дней. Его копия проверена по
SHA256 из [журнала загрузки](https://github.com/maxwell2010/go-smart-node/actions/runs/41645730986/job/125950441585).
Сводка сохраняет результат после истечения срока хранения архива.

## Что остаётся до выпуска

- Завершить финансовый обработчик и активацию нативного стейкинга. Проверить
  делегирование и конвертацию с `minOut`, штраф, погашение и завершение
  отложенного вывода после перезапуска. Сверить EVM, Bank, NFT и Validator
  в одной операции, включая расход газа и rollback.
- Проверить начальную загрузку контрактов и финансового genesis с проверкой
  обеспечения. На `33920c6` непустой native validator genesis закрыт до
  активации контроллера. Контрактные и Go-регрессии покрывают тестовые сценарии.
- Прогнать migration/IBC client upgrade с пакетом в пути. Текущий process CI
  подтверждает сохранение пакета при перезапуске на тех же бинарниках.
- Повторить установку и process gates на итоговом коммите, проверить его
  зависимости и снять замеры под целевой нагрузкой. Подписанный genesis,
  публичные seed/peer-адреса и измеренный минимум сервера пока не опубликованы.

[инструкцию оператора](README.md), для новых прогонов -
