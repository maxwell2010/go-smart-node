# Досрочное завершение голосования MintCandy

Проект для четырёх стартовых операторов. Включение требует отдельного принятого плана `mintcandy-bootstrap-unanimity-v1` с будущей высотой. Предложение № 1 и плата за выпуск DRC20 имеют собственные условия.

## Когда голосование завершается в текущем блоке

После исполнения плана ускорение доступно для вновь поданных предложений. Депозит открывает голосование обычным порядком. Каждый из четырёх зарегистрированных стартовых операторов с положительной силой и каждый владелец активной доли подают полный голос «за». Один адрес голосует один раз, даже если делегировал нескольким операторам. Кошелёк получения наград сам по себе права голоса не даёт.

В конце блока с голосами нода проверяет их итоговое состояние. Если достигнуто единогласие, штатный модуль управления подсчитывает вес, фиксирует результат и обрабатывает депозит. План обновления исполняется на указанной в нём высоте. При неполном согласии остаётся исходный срок, и участники могут менять голос до его окончания.

Для майнета операторы сверяются по адресам подписанного genesis. На изолированном tMSP проверяется состав из четырёх операторов на высоте активации. Регистрация или исключение, меняющие этот состав после активации, окончательно отключают ускорение. При превышении одной страницы активных позиций или привязок на оператора используется обычный срок. Это ограничивает работу ноды при досрочной проверке.

## Как включается правило

1. Операторы сверяют результаты репетиции, версии, SHA-256 и совместимость с текущим планом обновления. Действующие опубликованные бинарники требуют согласованного перехода для допуска нового имени плана.
2. После установки совместимой версии по согласованной процедуре подают отдельное предложение с выбранной высотой. Для голосования по самому правилу действуют прежние сроки. Перед подписью сверяют параметры управления и статус предыдущего плана.
3. На принятой высоте применяется сборка с обработчиком. Он проверяет решение управления, состав операторов и записывает минимальный номер нового предложения. Для ранее поданных заявок сохраняется исходный срок.
4. Для проверки результата сверяют событие `mintcandy_bootstrap_unanimity`, минимальный номер предложения и AppHash. У досрочно завершённого голосования появляется событие `mintcandy_unanimous_voting_closed`. Итог и вес голосов доступны в стандартном запросе предложения.
